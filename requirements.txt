# Ranges rather than exact pins: Streamlit Community Cloud picks its own
# Python (3.14 at time of writing), and an exact pin on a release that
# predates that Python has no matching wheel -- pip then fails on that line
# and silently skips everything after it in this file, which is how
# XlsxWriter went missing while pandas still imported from the base image.
# Upper bounds keep a future major release from breaking the app.
streamlit>=1.63,<2
pandas>=2.2,<3
numpy>=1.26,<3
altair>=5.5,<7
XlsxWriter>=3.1,<4
